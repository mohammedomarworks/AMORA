What AMORA does

Everything runs natively on your Mac. No Electron. No web wrapper. Pure Swift & Metal.

💬

AI Chat

Converse with a local Qwen 2.5 model running entirely on‑device via Metal GPU acceleration, or connect your own Anthropic / OpenAI API key. Apple Intelligence is also supported on compatible hardware.

🧠

Local Brain

Built‑in llama.cpp inference engine with quantized models (1.5 B / 0.5 B params). Downloads once, runs offline forever — SHA‑256 verified.

💾

Memory

Save explicit preferences that persist across sessions. A privacy validator automatically rejects passwords, API keys, financial data, and health records before anything is stored.

📝

Notes

Quick‑capture notes accessible from the Dynamic Island dashboard. Local storage, instant access, zero friction.

⏱

Timers

Set and manage timers directly from the island. Visual countdown, system notifications, and natural‑language creation through AI chat.

⚡

Automations

Create recurring and one‑shot automations with proactive suggestions. AMORA executes them deterministically through its sandboxed tool registry.

📋

Clipboard Privacy Guard

Monitors your clipboard history while automatically filtering password‑manager entries, transient data, and concealed types. Clipboard content is never sent to AI.

🎵

Media & Chrome Integration

Control Spotify, Apple Music, and YouTube playback from the island. The Chrome extension uses Native Messaging to sync YouTube media state in real time.

📊

System Monitor & Battery

Live system metrics, battery health diagnostics, and resource monitoring — always one glance away in the dashboard.

How it works

1

Clone & Build

Clone the repository, run ./Scripts/build-app.sh release, and launch AMORA.app.

2

Choose your AI

Download the built‑in Local Brain model, use Apple Intelligence, or enter a cloud API key. Or run with AI disabled — all core tools work deterministically.

3

Live in the island

AMORA floats near your notch and expands into a full workspace. Chat, set timers, take notes, control music — without leaving what you're doing.

Privacy by Design

AMORA is built to keep your data on your Mac.

🔒 Local-first inference

The default AI provider runs entirely on-device. No data leaves your Mac during inference.

🛡 Clipboard filtering

Password manager entries and concealed types are automatically skipped — never stored or sent anywhere.

🔑 Secure key storage

API keys are stored in the macOS Keychain, never written to disk in plain text.

🚫 Sandboxed tools

No shell execution. No arbitrary file access. Folder navigation limited to Desktop, Documents, and Downloads with user confirmation.

Full privacy policy and security invariants are documented in the README.
