Windows Orbit Beta

AMORA Orbit v0.6.0-beta is available for Windows x64 (64-bit Intel or AMD). Requires Windows 10 version 1809 (build 17763) or later, or Windows 11. The .NET 8 and Windows App SDK runtimes are bundled; the Visual C++ 2015–2022 x64 Redistributable may be needed if missing.

Download Windows x64 Beta

Choose AMORA.Orbit-v0.6.0-beta-win-x64.zip on the GitHub Releases page.

Beta and unsigned: The executable is not code-signed. Windows SmartScreen may show an “Unknown Publisher” warning.

Focus timers, media controls, battery and CPU/RAM status, local scheduled automations, and an optional Gemini assistant. Gemini setup: expand Orbit with Ctrl + Alt + O, open Settings, enter a Gemini API key, select Test Connection, then Save. The key is encrypted with Windows DPAPI; when Gemini is enabled, submitted prompts are sent to Google, while system-status sharing is opt-in.
